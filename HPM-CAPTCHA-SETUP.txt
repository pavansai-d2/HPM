HPM - CONTACT FORM PROTECTION (reCAPTCHA + anti-spam)

WHAT PROTECTS THE FORM (all server-side in contact-submit.php)
 1. Google reCAPTCHA v2 checkbox, verified on the server with Google.
    Missing/forged/expired token, wrong hostname, or Google unreachable = enquiry
    is NOT saved and NOT emailed (fails closed).
 2. Honeypot field (hidden from people). Bots that fill it get a fake "success"
    and nothing is saved.
 3. Rate limit per IP: 5 per 10 minutes, 20 per day. Change in config/config.php:
      'contact_limit_10min' => 5,
      'contact_limit_day'   => 20,
 4. Field validation (name, email, phone, message length, no HTML in name fields,
    header-injection safe) and same-site Origin check.
 5. Spam scoring: many links, mostly-links, script/HTML, BBCode, promo keywords
    (SEO/backlinks etc.), repetition. It looks at content only - never language or
    country - so genuine enquiries in Arabic, Japanese, Russian etc. pass.
    Suspected spam is saved to the Spam tab (never emailed).
 6. Duplicate protection: identical resubmission is saved only once.

ADMIN (admin/enquiries.php)
 - Inbox and Spam tabs, with counts. Mark as Spam / Not spam / Delete / Delete all spam.
 - Messages are shown as escaped plain text; no HTML runs, no external images load.
 - A strict Content-Security-Policy is sent on the page.

SETUP
 - Site key is in contact.html (data-sitekey) and secret key in config/config.php.
   Keep your LIVE config/config.php (database password + secret key); do not overwrite
   it with a different copy.
 - Domain(s) must be registered for the key in the Google reCAPTCHA console
   (haripalletmachinery.com and www.).
 - Database columns/table are created automatically on first use.
   database/2026-11-enquiry-spam-protection.sql is a manual equivalent if needed.
 - Without SMTP/PHPMailer configured, the notification uses PHP mail(); the From
   address must be a real mailbox on your domain.

NOTE
 - The "thank you" is the popup shown on contact.html after a successful send.
