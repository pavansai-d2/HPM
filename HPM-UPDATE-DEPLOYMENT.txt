HPM WEBSITE UPDATE — DEPLOYMENT NOTES
=====================================

Included updates
- Shared responsive breadcrumb styling with HPM orange/navy gradient accents and decorative shapes.
- Shared desktop Products dropdown and mobile Products category submenu on public pages.
- Mobile side menu logo, aligned close control, category expand/collapse controls and active link styling.
- Products catalogue opens with the first category only; selecting a category shows only that category.
- Product popup includes Before and After image slots, and headings use HPM navy/orange theme colors.
- Admin dashboard displays the account label as Admin and includes a logout icon.
- Shared responsive banner rules preserve the complete banner image/video artwork without cover cropping.

IMPORTANT DATABASE STEP — REQUIRED FOR BEFORE/AFTER IMAGES
1. Back up the live hpm_catalogue database.
2. Open phpMyAdmin and select the hpm_catalogue database.
3. Import/run database/migrate-product-before-after.sql exactly once.
4. Upload the updated project files to the website hosting, preserving existing config/config.php and uploaded product files.
5. In Admin > Products, edit each product and upload its Before image and After image. If not supplied, the popup temporarily uses the main product image as a fallback.
6. Test products.php, each category submenu link, product popup, admin login/logout and mobile navigation.

UPLOAD NOTES
- Keep the existing config/config.php and includes/mail-config.php server-specific values; do not overwrite them with example configs.
- Preserve uploads/products/ if it already contains product images.
- Test first on staging/local XAMPP before replacing the live website.
- The before/after migration must run before deploying the updated API/editor, otherwise the API query will fail because the new columns will not exist.

Banner behaviour
- Images are displayed with background-size: contain. This prevents cropping but may leave intentional empty space around the image on screens with a different aspect ratio.
- Banner text is hidden on the homepage to keep the artwork unobstructed as requested.
